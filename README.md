# Textbook Knowledge Builder

An LLM-powered pipeline for converting high-school textbooks into structured, traceable educational knowledge for downstream RAG applications.

## Status

Work in progress.

## Planned Pipeline

```text
Textbook PDF
    ↓
PDF Parsing
    ↓
Document Structure Extraction
    ↓
LLM Knowledge Extraction
    ↓
Schema Validation
    ↓
Structured Knowledge Base
